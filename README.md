# комната 12

Караоке-бокс №12, два года одной комнаты. 2005 — четверо друзей, перегруз, MIDI-бэнд, всё громко.
2017 — ты один, минус тихий, бас соседей сквозь стену. Одна и та же мелодия звучит в обоих мирах,
меняется только комната вокруг неё. Прыжок между годами всегда случается на границе такта, темп
не меняется. Каждые 8 тактов, проведённых в 2005-м, при возврате в 2017 приносят назад один
фрагмент звучания (максимум 4) — песню, которую пели вчетвером, не спеть одному, но можно
приносить её обратно по частям.

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # production-сборка в dist/
```

## Клавиатура

- `пробел` — играть / стоп
- `5` / `7` — прыжок в 2005 / 2017 (на ближайшей границе такта)
- `←` `→` — тон (−3…+3)
- `z x c v` — заглушить голос / минус / пол / бубен

Ручное управление (клик по году, тону, паттернам) переключает пульт из режима «по сценарию» в
режим «руками»; обратно — кнопкой «режим».

## Схема сигнала

```
инструмент(ы) голоса ─┐
                       ├─→ стойка эффектов (4 слота) ─→ Tone.Channel (volume/pan/mute/solo) ─┬─→ шина «микрофон» ─┐
инструменты минуса ────┼─→ стойка эффектов ─→ канал минуса ──────────────────────────────────┼─→ шина «музыка»  ─┤
инструменты пола ──────┼─→ стойка эффектов ─→ канал пола ─────────────────────────────────────┤                  ├─→ мастер
инструменты бубна ─────┘─→ стойка эффектов ─→ канал бубна ─────────────────────────────────────┘                  │  (StereoWidener →
                                                                                                                     │   Reverb → Limiter)
каждый канал также шлёт сигнал в общий эхо-бас (FeedbackDelay) ────────────────────────────────────────────────────┘
                                                                                                    ─→ Tone.Destination
```

У каждого голоса своя стойка из 4 слотов, в каждом — любой из 18 эффектов Tone.js (AutoFilter,
AutoPanner, AutoWah, BitCrusher, Chebyshev, Chorus, Distortion, FeedbackDelay, Freeverb,
FrequencyShifter, JCReverb, Phaser, PingPongDelay, PitchShift, Reverb, StereoWidener, Tremolo,
Vibrato) с переключателем wet и одним главным параметром. Прыжок между годами переключает пресеты
всех стоек разом (`src/audio/effects/presets.js`); правки, сделанные вручную, хранятся отдельно
для 2005 и для 2017.

## Структура

```
src/
  audio/    engine.js, voices.js, transport.js, trace.js, effects/{registry,presets,rack}.js
  music/    score.js — константы пьесы (MEL, CHO, CH, RT, SEC, SCORE)
  state/    store.js — состояние на zustand
  ui/       App.jsx и компоненты интерфейса
```

Данные, визуал и музыкальная механика перенесены из прототипа `reference/komnata12.html`
(не входит в репозиторий, см. `.gitignore`).
